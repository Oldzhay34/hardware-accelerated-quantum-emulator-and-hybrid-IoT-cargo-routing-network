# hls/

Vitis HLS kaynakları: statevector emülasyon çekirdeği (Faz 2), C-simülasyon test bankları, Tcl derleme betikleri, sentez raporları (`.gitignore`'da hariç tutulmuş büyük ikili çıktılar dışında).

Anayasa Prensip III (Donanım Bütçesi Önce) ve Prensip V (Donanımsız Süreklilik) bu dizin için bağlayıcıdır: her tasarım kararı önce bellek bütçesine karşı doğrulanır; kart yokken de C-sim/cosim ile geliştirme sürebilir.

Alt dal 2.0 (bankalama tuzağı) okunmadan bu dizine kod yazılmaz.
